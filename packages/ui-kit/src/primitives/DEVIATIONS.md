# Primitive ↔ reference deviations

What T-016's visual check should shoot each primitive against, and what it should expect to differ.

`test/primitives-parity.test.tsx` already compiles every primitive's Tailwind utilities and diffs the
resulting declarations against the reference rule named below; the **Deviations** column is that
test's `DEVIATIONS` table in prose, plus the differences that are not expressible as a CSS property.
No primitive has had a screenshot taken yet — T-016's harness did not exist when this was written, so
every row below is still owed one. It exists now: close the gap with
`pnpm visual-check --screen <id> --url <url>` against the "Shoot against" column.

Line numbers are into `docs/design-reference/Komtru — UI Screens Living Master File.html`.
