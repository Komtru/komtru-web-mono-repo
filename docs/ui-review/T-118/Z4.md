## Deviations

**Shell chrome and the stand-in.** The built screen sits in `AppShell` (shot with `--content main`) and its actions are in the page flow above the real tab bar, where the reference pins them in a sticky footer; the tab bar and the moved buttons light the foot of the heat map. The shot ran against the production build and a canned stand-in for the platform (trade ids mapped to states, one proxy adding the sealed session cookie), so names, amounts, dates and photos are illustrative.

**Real differences (intended, and why)**

- **One column, not two.** The reference draws the seller's proof and the delivery evidence as two photo columns. The built screen stacks them: the proof as a three-up photo grid (private files read as short-lived signed URLs), the delivery evidence as rows, because a self-arranged delivery has a waybill, a vehicle and delivery signals, not courier photos or a GPS tag.
- **No "GPS-tagged by courier".** Nothing the platform records carries it for a self-arranged delivery.
- **The countdown shows the end date, not "41h remaining"**, and a plain line says what silence does. A remaining-hours count would be wrong a minute later (the kit's countdown strip says "until").
- **"Report an issue instead" is not a control.** Disputes are F-032, so the screen says it is not in the app yet rather than draw a button that does nothing.
- An item card above the proof, as the other trade screens have it.
