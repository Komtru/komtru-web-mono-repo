## Deviations

<!-- One line per deviation the heat map shows: what differs, where, and whether it is intended.
     Everything below this comment survives the next run; everything above it is regenerated. -->

**Shell chrome.** The reference draws these as full-screen mobile frames with their own top bar and a
pinned footer, and no tab bar. The built screens sit inside `AppShell`. The shot is taken with
`--content main`, so it starts at the screen's own content and the shell's brand row does not shift every
line; the tab bar still sits at the bottom of the compared area, and actions are in the page flow
(`ActionStack`) rather than `.btn-sticky`, because a pinned footer would sit on the tab bar. What the heat
map shows is therefore real differences in what each screen says and holds, listed below.

**Shot against a stub.** The shot ran against the real app with a canned stand-in for the backend (trade
ids mapped to states) because no backend runs in the review environment; copy and layout are the real
screens, the data is illustrative.

- **No "Reason / Note".** The counter endpoint takes no note, so the field is not drawn. "What's changing" and "Revised terms summary" (item price, the address, other terms unchanged) are built, with the footnote that the previous proposal is not the accepted agreement; the price field is formatted as naira. The summary has no Delivery row of the reference's ("Buyer pickup"): that is not a term the platform stores.
- **Only price and address can be changed here.** The drawn Delivery row ("Courier / Buyer pickup") is not a term the platform stores, and item details are not editable in a counter on this screen.
- **The inputs come first and "What's changing" follows**, because the reference draws the diff over a form that is not shown. Each change is a `CounterDiffRow`: the old value struck through, the new in emerald.
- **"Send counter-proposal" is disabled until something differs**, with a line saying so. The counter carries the trade's revision, so a counter against a trade that moved on is refused rather than landing.
