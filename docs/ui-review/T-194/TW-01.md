## Deviations

**Shell chrome and the stand-in.** The reference draws a full-screen mobile frame with its own top bar and pinned footer; the built screen sits in `AppShell` (brand row, mode switch, tab bar), `ScreenHeader` stands in for the drawn bar and the actions (`ActionStack`) sit in the page flow above the real tab bar, so the built shot is taller and every row below the header is offset. The shot walks the real screen in Chromium against `next dev`, with the platform's routes answered from canned data (TechEdge NG, iPhone 13 · 128GB), so names and amounts are illustrative. Amounts print with kobo (`₦195,000.00`) as the rest of the app does; the reference prints whole naira. The reference's `₦198,500` total is ₦195,000 + the ₦3,500 Buyer Protection Fee here, not ₦3,500 delivery.

**Real differences (intended, and why)**

- **Funding-window countdown is not drawn, and "six hours" is not claimed.** The trade the platform returns carries no funding deadline and nothing in the trade service sets one for a trade waiting on payment, so a "05:58:12 remaining" strip would be invented. The guard banner keeps the reference's title and its second sentence, and drops "This trade expires six hours after creation." (owner question O1).
- **Workspace chrome above the terms.** The overview keeps F-022's tab strip, "Terms agreed" hero and "Agreement recorded" banner (CWT-01), which TW-01's reference does not draw; the agreed terms, payment status, next step and the two actions follow in the reference's order. The agreement-history timeline, the fee list, the trade code and a quiet "Trade policies" link are also kept from CWT-01.
- **Delivery row reads `Courier · ₦3,500`** (the seller's committed charge from the terms) where the reference prints `Courier · calculated`; "Withdraw from trade" opens the Actions tab, where F-022's confirmation sheet lives.
