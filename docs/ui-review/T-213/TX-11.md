**The 560px comparison is the phone layout, not the tablet one.** The tablet reference frame is 560px wide but the app's tablet breakpoint (`md`) is 768px, so this score compares the phone screen with the tablet drawing. The tablet layout was shot with `pnpm visual-capture --walk {id} --app http://localhost:3101 --width 820` and read by eye against the reference; no pixel score exists for it.

- At 820px: chip row, list left, detail pane right (item, buyer, amount, payment, next step, one action). Matches the drawing's structure.
- **'Message buyer' button omitted** (messaging deferred). The detail pane shows the first order until another is chosen; the reference list is grouped under 'Ready to ship', ours is flat with a stage chip per order.
- Same omissions as DX-18: no Returns chip, no Due, no Create listing.
- The chosen order is marked with `aria-pressed` and choosing one moves focus to the pane's heading. The filter and choice survive a resize.
