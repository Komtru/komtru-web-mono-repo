# AC10 — Universal case layout (T-141)

- **Reference:** the case layout of OP-20 (`docs/design-reference/Komtru — UI Living Master v2.html`, line 9220 on) and `CaseLayout` / `DecisionPanel` in `@komtru/ui-kit`.
- **Built:** `/queue/cases/[id]` in `apps/operations-app` (`src/cases/CaseDetail.tsx`)
- **Method:** as for the other T-141 screens, markup and test comparison; no pixel diff (see OP-01).

## Deviations

- **Left column.** "What we know" (the facts the owning module keeps on the index), "Evidence asked for" (with Mark fulfilled and Cancel request) and the Trust Trail. The reference's dispute-specific panels (buyer's evidence, seller's response) belong to the owning module's ticket (T-143 for disputes); the universal case does not hold them.
- **Right column.** The advisory (from `GET /cases/:id/advisory`) sits in `DecisionPanel`'s advisory box, then "a human decides, always", then the form: Outcome, Reason, Policy, Clause and Record decision. The reference offers four fixed outcome buttons for a dispute; the universal case has no outcome list, so the outcome is typed. The policy cite footer is built from the typed policy and clause.
- **The advisory never fills the form**, never enables Record decision and is never in the request body (tested). Record decision stays disabled until outcome, reason, policy and clause are all typed.
- **Who can decide.** Only the owner sees the form. An unowned case offers Take this case; someone else's case offers Reassign to me with a required reason; a role with `cases.view` only sees the case and the advisory.
- **Work this case.** Escalate, Change priority and Request evidence, each with the reason the platform requires. Reassigning to another person needs a staff directory and is not offered.
- **After you decide** ("Both parties are told, with the policy · Instantly") is not drawn: it is a promise about the owning module's follow-through.
