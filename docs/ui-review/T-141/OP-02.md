## Deviations

- **Chips.** Area chips (All, then each area present) narrow the loaded cases on screen; the platform filters by type, not area. The count in "All (n)" is the number loaded, not a server total.
- **Bulk bar** ("2 selected · Reassign / Add a note / Clear") is not drawn: no bulk endpoint, and reassign needs a per-case reason.
- **Columns.** Case, Area, What, Priority, Clock. The reference's "Why it's here" has no field behind it; Priority stands in, since the queue is ordered by it.
- **Footer** reads "Showing n so far" with a Load more button instead of "Showing 5 of 6": lists are cursor-paginated and have no total.
- **Row action.** The case code is the link; the reference's Open/Review button is not repeated.
