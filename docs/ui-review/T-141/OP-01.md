# OP-01 — Today (T-141)

- **Reference:** `docs/design-reference/Komtru — UI Living Master v2.html` line 9008
- **Built:** `/queue` in `apps/operations-app`
- **Method:** compared by reading the reference markup (extracted with the base64 images stripped) against the built component and its test output. The pixel-diff harness was not run: every one of these screens sits behind a staff session and `GET /admin/me`, which does not exist yet, and the cases API has no fixture server, so the built page cannot be opened with data. Same limit T-140 recorded for OP-28. A screenshot pass is the first thing to do once `GET /admin/me` lands.

## Deviations

- **Rail.** The reference's nine-item rail (Today, My work, Trades, Money...) is T-140's twelve sections. Today, My work, Team queue, Alerts and Cases are a tab strip under the page head, not rail items.
- **Tiles.** Four `KpiCard`s as in the reference, but the fourth is "Clock at risk" (backend `slaAtRisk`), not "Decided today": the platform has no decided-today count or median-first-response figure.
- **Do these first.** Drawn as a `DataTable` of the first five of `view=mine` with case, what and clock. The reference's "Why now" column has no field behind it, so it is dropped; the case code is the link.
- **Where the work is** (area, waiting, oldest, clock health) is not drawn: no per-area totals or oldest-clock read exists.
- **Just decided** (Trust Trail feed) is not drawn: no recent-decisions read exists.
- **Escalated** shows the first five escalated cases with a View all link to Alerts, where the reference shows three one-line items.
- The day and shift line ("Tuesday · 3 shifts covered · queues healthy") is not drawn: no shift data.
