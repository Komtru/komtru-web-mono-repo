Shot at `/signup` with nothing typed.

- **"Continue", not "Send verification code"** (intended). TOS1 has to come before the account
  exists, and the platform opens the account and sends the code in the one `POST /auth/register`
  call that also records the accepted Terms (M1 §10.1). So E2 keeps the details, TOS1 makes the call,
  and E2's button no longer sends anything; naming it after a send it does not do would be wrong.
- The reference shows a typed example number (`0802 341 5567`); the built field shows its
  placeholder. Content, not layout.
