## Deviations

- **Shell.** The built page sits in the T-140 console frame: the OP-01 twelve-section sidebar (Work Queue, Identity / KYB, Trust Graph for this role) instead of the reference's eight-item rail, no global search bar, authority chip or avatar. Intended (T-140 scope, nav by permission).
- **Tabs.** A "Verification queue / Duplicate flags" strip is added above the filters, each shown only with `verification.view` / `duplicate_flag.view`. The reference has no flags view; T-144 asks for duplicate-identity flags on the same layout.
- **Who.** The queue carries the kind of check and the user id, never a name (T-050 keeps PII out of the review queue). "Who" shows the check ("Business registration (CAC)") with case number and the tail of the user id, not "Zaza Fashion".
- **Provider result.** The provider's own words are not persisted (T-050). The column shows "Needs a person", "Duplicate identity" or "Duplicate identity, escalated", the states the queue actually holds, not "BVN matched" or "Name mismatch".
- **Filter chips** carry no counts ("All (9)"): the queue returns no per-kind totals. Individuals/Businesses filter on the platform; "Waiting over 24h" filters the pages loaded.
- **"Park network applications"** button is not drawn: that screen is T-147.
- **Table** has a visible "Action" header over the Review links and a "Showing n" footer (the shared DataTable pattern); the review control is a link, as it navigates.
- Row typography, chip colours and spacing follow ui-kit's DataTable and Chip, which differ from the reference by a few pixels (heat map is concentrated on text).
