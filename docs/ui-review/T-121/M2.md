## Deviations

- **Rows use ui-kit `TermList`/`TermRow`** rather than `.verify-row`. The status chip sits at the right, with the detail line under it (CAC number, bank and last four digits, address).
- **Storefront row follows the application.** Verified when approved, Verifying while in review, Changes requested only when staff named one of its fields, otherwise Not yet.
- **Owner identity row** is read from the ID and selfie checks, not drawn from the reference's "Checked 2024".
- **States not drawn in the reference, added:** not started, draft (continue to the first unfinished step), in review, changes requested (each named change links to the step that holds it), approved (links to the live shop).
- **Info banner** kept verbatim.
- **Mobile tab bar** shows Account as the current tab, as the reference's `data-mobile-section` marks it.
