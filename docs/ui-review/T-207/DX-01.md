## Deviations

<!-- One line per deviation the heat map shows: what differs, where, and whether it is intended.
     Everything below this comment survives the next run; everything above it is regenerated. -->

Built as the drawing at 1040px, 6.2% of pixels differ (type rendering and the images below). Read against the reference:

- **Wordmark.** The drawing uses a PNG wordmark; the app uses its own `KomtruLogo` (mark and "Komtru" in Space Grotesk), as on every other screen. Intended.
- **Gradient.** The drawing ends at `#1A2440`, which is not a token. The panel runs `--komtru-midnight` into a 10% mix with `--trust-indigo`, a slightly bluer end. Intended (the lint rule forbids raw hex).
- **"Keep me signed in on this device" is not built.** The drawing shows it as a line of text beside "Forgot password?". The platform has no session-length choice, so a checkbox would do nothing. Only "Forgot password?" is drawn, at the right of the row. **Needs the owner:** a platform decision on a longer-lived session.
- **Trade Code entry carries one extra line**, "You'll log in first, then we'll show the trade." The drawing says a visitor can start "without an account". They cannot: `/find` and the lookup behind it need a session. Find sends the code to `/find?code=...`; the session gate sends a logged-out visitor to log in and brings them back to it (the `next` keeps the query). A public lookup would be a platform change and is the owner's call.
- **Fields.** Empty, with the app's `080X XXX XXXX` placeholder; the drawing shows filled sample values. No Back link on log in (the drawing has none).
- The right column is capped at 440px and centred in its half, so a 1920px window does not stretch the form. The drawing is only 1232px wide.
- The form keeps its typed values across a resize to tablet and back (suite and a real browser).
