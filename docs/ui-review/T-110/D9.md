## Deviations

Re-shot for **T-110** against the real screen at `/account` (the earlier shot on this file was
T-013's, against the `Shells/DesktopShell` → `Account` Storybook story; the shell findings it
recorded still hold and are repeated where they still apply).

**Shell chrome — lands on the reference**

- The 180px sidebar, its hairline, the `.ds-logo` lockup reading "Account" rather than "Komtru", the
  `.dweb-item` rail and the 24px content padding all match.
- The page background is painted by the shell (`bg-surface-primary`), where the reference states it
  on the drawn frame. Deliberate — see `packages/ui-kit/src/shells/DEVIATIONS.md`.

**Intended differences**

- **A sixth rail item, Park Agent, and a seventh for anyone who has sold.** The acceptance criteria
  put Payouts in Account for anyone who has sold and the Park Agent entry point here rather than in
  a tab (design §6.3, §7.6). The viewer in this shot has neither sold nor applied, so Payouts is
  absent and Park Agent reads "Not yet set up".
- **The content pane is the section list, not the Personal Info form.** `/account` is the index:
  every section behind it — Personal info, Verification, Trust history, Notifications, Security
  (T-126), Payouts (T-124), the hub application (T-130) — is another ticket's screen. The reference
  draws the shell with its first section already open, which is what `/account/personal-info` will
  be once T-126 builds it.
- **Nothing in the rail is marked current**, for the same reason: the index is not one of the
  sections. The reference shows Personal Info in the indigo `.dweb-item.active` pill.
- **Sentence case in the rail** ("Personal info", "Trust history") against the reference's title
  case. The product's own voice, set in T-012: sentence case everywhere except proper nouns.

**Still open from T-013, unchanged by this ticket**

- `.btn-primary` is `width:100%` and D9's "Save changes" is written `width:auto`; `<Button>` still
  has no width prop. T-126 meets this when it builds the form.
